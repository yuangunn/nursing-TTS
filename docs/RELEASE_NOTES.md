## 간호기록 음성 녹음 생성기 — beta

### 이번 버전 (v0.1.3-beta, 2026-10-16)
- **처음 설정 마법사**가 환경 점검 → 백엔드 설치(진행률·예상 시간) → 음성 엔진 → 첫 목소리 등록을 안내합니다. 설치 뒤 앱을 켤 때마다 새 버전을 확인하고(이 버전 알림 받지 않기 가능) 백엔드가 늦게 올라와도 화면이 자동으로 목록을 다시 받아옵니다.
- 작업 순서: 1 목소리 등록 → 2 대본 생성 → 3 녹음 만들기 → 4 대량 생성 → 5 결과물·검수. 대본 생성 화면에서 대본 N개를 읽고 문장마다 "이렇게 말 안 한다"를 표시해 전달할 수 있습니다.
- 목소리: 생성 예시 문장으로 들어 보기(원음 재생 없음, 번들 데모 포함), 음높이·속도 프리셋(녹음 생성에도 적용), 이름·성별 수정, 정렬. 공개 화자 15명("기본 음성 여/남")을 함께 제공합니다.
- 대본: 병동 수술 31종·항암 13종 지식베이스에서 진단·주호소·현병력·치료 계획이 서로 맞게 나오고, 항암은 정규 차수/부작용 입원을 구분합니다. 수술명은 병동에서 부르는 여러 읽기로, 낙상은 존스홉킨스, 욕창은 Braden 기준으로 "낙상 8점으로 중위험군이시고"처럼 말합니다. 퇴원간호는 퇴원 당일 기록이며 병동 퇴원 설명문대로 교육합니다. 기본 말투는 격식체.
- 소음: 병동에서 녹음한 실제 소음만 쓰고, 켜진 소음 각각이 녹음마다 확률적으로 섞입니다. 결과물 목록에 소음 종류·레벨이 보입니다.
- 표 데이터 가져오기: CSV·엑셀의 열을 환자 정보·체크 항목에 연결하고 셀 값의 뜻을 정해 행마다 대본·녹음을 만듭니다.
- 전문용어(CER, ASR 등)에 마우스를 올리면 설명이 뜹니다.

### 설치 (macOS)
1. Apple Silicon은 `-arm64.dmg`, Intel Mac은 `-x64.dmg`를 받아 앱을 Applications로 끌어다 놓습니다.
2. 서명되지 않은 베타 빌드라 첫 실행 시 차단됩니다. **Finder에서 앱을 우클릭 → 열기**를 하거나 터미널에서
   `xattr -dr com.apple.quarantine /Applications/NursingTTS.app` 을 실행한 뒤 여세요.
3. Python 3.10 이상이 필요합니다 (`brew install python`). 앱을 처음 켜면 **처음 설정 마법사**가 환경 점검 → 백엔드 설치(진행률·예상 시간 표시) → 음성 엔진 → 첫 목소리 등록을 안내합니다. 기본 설치는 보통 2~4분 걸립니다.
4. 목소리 복제 엔진(Qwen3-TTS, 약 6.5 GB)은 마법사나 설정 탭에서 체크해 설치합니다. 엔진 없이도 시스템 음성으로 전체 흐름을 바로 확인할 수 있습니다.

### 설치 (Windows)
`-win-x64.exe` 설치 파일 실행 → 처음 설정 마법사를 따라가면 됩니다. Python 3.10 이상(python.org, "Add to PATH" 체크) 필요. NVIDIA GPU가 있으면 복제 엔진 설치 때 CUDA용 PyTorch를 자동으로 받습니다.

### 알려진 제한
- 코드 서명/공증 없음 (베타). 자동 다운로드·설치는 서명 뒤에 붙습니다.
- 목소리 복제 품질은 선택한 모델과 GPU에 따라 다릅니다. Mac 16 GB에서는 대량 생성 대신 소량 생성을 권합니다.
