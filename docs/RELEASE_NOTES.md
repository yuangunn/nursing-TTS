## 소리차트 — 간호기록 음성 녹음 생성기 beta

### 이번 버전 (v0.1.12-beta, 2026-10-17)
- **대화형 간호정보조사의 흐름**: 간호사가 질문 사이사이에 차트를 읊지 않습니다. 환자와 문답을 끝낸 뒤 "네, 말씀 감사합니다. 확인한 내용 정리해서 기록하겠습니다." 하고 활력징후·점수·간호 문제 등을 기록합니다. 대화한 환자는 의식 명료·지남력 있음·언어 장애 없음으로 맞춥니다.
- **말투**: "~하신 거 없으시고"처럼 증상에 존대가 붙던 문구를 "~한 것 없고/없습니다"로 고쳤고, 우울 선별 결과 문장("흥미 떨어진 날이 없음 된다고")을 자연스럽게 바꿨습니다.

### 이전 버전 (v0.1.11-beta, 2026-10-17)
- **간호정보조사 겹침 제거**: 수면·보행·식사량·체중 변화가 본 사정과 선별 문진에서 두 번 나오던 것을 한 번으로 합쳤습니다(문진형 문구는 변형으로 남음).
- **수술 후 기록(POD 0)을 병동 범주 순서로 재편**: 환자 확인·도착 → 바이탈 사인·의식 → 가지고 온 주입·배액관 관찰 → 수술 부위 관찰 → 통증 사정 → 약물 투여(항생제·항구토제·항응고제) → 수술 후 처치(산소, DVT 예방 IPC, ice bag, 거상, 압박) → 금식 유지 기간 교육 → 자세·활동 교육 → 배액관 관리 → 도뇨관 관리 → 수술별 관찰·교육 → 알려야 할 증상. 배액관·도뇨관은 관찰과 관리 교육을 나누고, 상처 교육은 알려야 할 증상에 합쳤습니다.

### 이전 버전 (v0.1.10-beta, 2026-10-17)
- **퇴원 간호기록을 병동 범주 순서로 재편**: 환자 확인(입원 팔찌·정맥주사 제거 부위) → 약 → 다음 외래·입원 일자, 검사와 검사 전 주의 → 일반적인 건강관리 → 주의사항 → 상처·장치 관리 → 의료진에게 알려야 할 상황 → 연계·이해도. 수술·항암별 병동 설명문 문구는 범주별로 들어가고 그 범주의 일반 문장은 빠져서 같은 교육(상처 관리 등)이 두 번 나오지 않습니다. 상처 이상 안내와 응급 내원 기준은 "알려야 할 상황" 하나로 합쳤습니다.
- **격식체 어미**: 격식체 안에서 문장을 이어 붙일 때 "~했구요," 대신 "~하였고,"를 씁니다.

### 이전 버전 (v0.1.9-beta, 2026-10-17)
- **간호정보조사**: 입원·수술이 걱정된다고 하면 "최근 2주 동안 며칠이나…" 정서평가 두 질문(우울·흥미 저하, 없음/며칠/일주일 이상/거의 매일)을 이어 묻고 결과에 맞춰 상담 연계를 말합니다. 흡연·음주 환자에게는 대답 직후 금연·금주 교육을 하고, 서술형 기록에도 교육 문장이 들어갑니다. "간호진단은 …입니다" 문장은 대본 생성·대량 생성의 체크박스로 넣고 뺄 수 있습니다.
- **수술 후 기록(S3-1) = POD 0**: 회복실에서 병실로 올라온 직후 기록만 만듭니다(POD 1·2 선택지 제거). **경과기록(S6)**은 "지금 경과기록 하겠습니다"로 시작해 아침 라운딩부터 오후 활동·배액, 저녁 활력징후, 프로토콜 체크까지 그날의 기록을 시각 순서로 말합니다(체크 항목마다 시각).
- 유방암 항암 환자의 진료과는 유방외과입니다(혈액종양내과 아님).

### 이전 버전 (v0.1.8-beta, 2026-10-17)
- **대화형 간호정보조사가 "어떻게 오셨어요?"로 시작**: 환자가 자기 말로 사정을 이야기하고(가끔 장황하게, 언제부터인지·무슨 수술이었는지 기억이 흐릿하게), 간호사가 거기서 주호소·발생 시기·경로·목적을 기록 용어로 한 줄 확인합니다. 흐릿한 대답에는 간호사가 되짚어 묻습니다("네, 맹장 수술이요", "약 봉투 보여 주세요").
- **녹음 만들기의 환자 목소리**: 간호사·환자 목소리를 나란히 두고, "자동"이 실제로 어떤 목소리 중에서 고르는지 보여 주며, 고른 목소리는 예시를 바로 들을 수 있습니다. 등록 목소리의 음높이·속도 프리셋이 환자 줄에도 적용됩니다.

### 이전 버전 (v0.1.7-beta, 2026-10-17)
- **앱 이름과 아이콘**: 앱 이름은 **소리차트**(SoriChart)로, Dock·시작 메뉴·창 제목·화면 상단에 보입니다(설치 파일명과 데이터 폴더는 그대로 `NursingTTS`). 전용 아이콘(청록 바탕의 기록지와 소리 파형)이 Electron 기본 아이콘을 대신합니다.

### 이전 버전 (v0.1.6-beta, 2026-10-17)
- **설치 파일만 실행하면 기본 목소리와 소음까지**: 모든 설치 파일(일반·-offline)에 기본 목소리 15명(Zeroth-Korean, CC BY 4.0)과 병동 소음 클립(룸톤·네뷸라이저·중환자실·모니터 알람·회진 대화)이 들어 있어 첫 실행 때 데이터 폴더에 자동으로 들어갑니다. `-offline` 설치 파일(mac Apple Silicon·Windows x64; Intel Mac은 PyTorch 미지원)은 여기에 백엔드(Python·패키지·Qwen3-TTS 스택)까지 내장되어 인터넷 없이 바로 뜹니다. 온디바이스 모델(약 5 GB)만 따로 넣습니다.

### 이전 버전 (v0.1.5-beta, 2026-10-17)
- **한 번에 설치되는 "-offline" 설치 파일**: `NursingTTS-offline-<버전>-mac-arm64.dmg`, `-win-x64.exe`에는 Python과 모든 패키지, Qwen3-TTS 복제 스택(Windows는 CPU PyTorch)이 들어 있어 설치만 하면 pip 없이 백엔드가 뜹니다. 모델(약 5 GB)은 설정 → 로컬 모델 폴더에 복사하거나 `--models` 번들로, NVIDIA CUDA는 `.ps1 -Qwen -Cuda` 번들로 따로 옮깁니다.
- **목소리·소음 옮기기**: `scripts/build-offline-bundle.sh --data`(Windows `-Data`)로 만든 번들을 다른 PC에서 가져오면 이 PC의 등록 목소리와 소음 클립이 그대로 들어갑니다(이미 있는 항목은 덮어쓰지 않음).

### 이전 버전 (v0.1.4-beta, 2026-10-17)
- **모든 서식이 한 환자에서 나옵니다**: 수술 전·후 설명, 이벤트 기록, 퇴원, 인계, 경과기록도 간호정보조사처럼 환자 사실에서 항목을 도출하고 자동 검사로 모순(POD와 시점, 처방과 투약, 금식과 물 시작, PCA 제거와 재사정 …)을 걸러 다시 뽑습니다. 프로토콜 체크리스트는 경과기록(S6)에만 붙습니다. BKA는 "비케이에이/무릎 아래쪽 절단".
- **간호정보조사 낙상력** 항목(낙상 입원이면 자동 '있음', 존스홉킨스 +5)과 어투별 어미 다양화(격식 하였습니다/했습니다/드렸습니다, 연결 고요/구요, 기록 함/하였음).
- **대본 생성 ↔ 녹음 만들기 분리**: 대본 생성(🎲 무작위 또는 ✎ 직접 설정)에서 읽고 고친 대본을 🧺 바구니에 담고, 녹음 만들기는 바구니의 대본을 목소리·소음 옵션으로 한 번에 녹음합니다. "같은 대본 다른 말투로" 버튼.
- **대화형 간호정보조사**: 묻는 항목이 간호사 질문(~까요?)과 환자 대답(~어요/네/아니오, 80세 이상은 반말)으로 나뉘고, 녹음은 두 목소리(환자 = 성별에 맞는 등록 목소리 또는 간호사 목소리 변조). 정답 텍스트는 순수 전사, json에 화자 표시.
- **설정**: 동작 원리 안내(무엇이 로컬이고 무엇이 밖으로 나가는지), 로컬 모델 위치·다운로드 링크·📁 모델 폴더 열기, LLM 키 테스트.
- **인트라넷(오프라인) 설치**: 인터넷 되는 PC에서 `scripts/build-offline-bundle`로 Python+패키지(+모델) zip을 만들고, 마법사나 설정에서 "📦 오프라인 번들 가져오기"로 넣으면 pip·다운로드 없이 백엔드가 뜹니다. 이 릴리스에 mac(arm64)·Windows(CPU) 번들을 함께 올립니다.

### 이전 버전 (v0.1.3-beta, 2026-10-16)
처음 설정 마법사, 새 버전 확인, 작업 순서 사이드바, 목소리 예시·프리셋·공개 화자 15명, 병동 지식베이스 기반 대본, 실제 소음만 사용, 표 데이터 가져오기, 용어 설명.

### 설치 (macOS)
1. Apple Silicon은 `-arm64.dmg`, Intel Mac은 `-x64.dmg`를 받아 앱을 Applications로 끌어다 놓습니다.
2. 서명되지 않은 베타 빌드라 첫 실행 시 차단됩니다. **Finder에서 앱을 우클릭 → 열기**를 하거나 터미널에서
   `xattr -dr com.apple.quarantine /Applications/NursingTTS.app` 을 실행한 뒤 여세요.
3. Python 3.10 이상이 필요합니다 (`brew install python`). 인터넷이 없는 PC는 아래 "오프라인 번들"을 쓰세요. 앱을 처음 켜면 **처음 설정 마법사**가 환경 점검 → 백엔드 설치(진행률·예상 시간 표시) → 음성 엔진 → 첫 목소리 등록을 안내합니다. 기본 설치는 보통 2~4분 걸립니다.
4. 목소리 복제 엔진(Qwen3-TTS, 약 6.5 GB)은 마법사나 설정 탭에서 체크해 설치합니다. 엔진 없이도 시스템 음성으로 전체 흐름을 바로 확인할 수 있습니다.

### 설치 (Windows)
`-win-x64.exe` 설치 파일 실행 → 처음 설정 마법사를 따라가면 됩니다. Python 3.10 이상(python.org, "Add to PATH" 체크) 필요. NVIDIA GPU가 있으면 복제 엔진 설치 때 CUDA용 PyTorch를 자동으로 받습니다.

### 인트라넷(인터넷 없는 PC)
이 릴리스의 `nursing-tts-offline-<os>-<arch>-qwen.zip`을 받아 두었다가(또는 인터넷 되는 PC에서 `scripts/build-offline-bundle.sh --qwen --models`로 모델까지 넣어 만든 zip), 처음 설정 마법사 2단계나 설정 → 백엔드의 "📦 오프라인 번들(zip) 가져오기"로 선택하면 Python 설치 없이 백엔드가 뜹니다. 모델이 번들에 없으면 설정 → 로컬 모델의 폴더에 복사합니다.

### 알려진 제한
- 코드 서명/공증 없음 (베타). 자동 다운로드·설치는 서명 뒤에 붙습니다.
- 목소리 복제 품질은 선택한 모델과 GPU에 따라 다릅니다. Mac 16 GB에서는 대량 생성 대신 소량 생성을 권합니다.
