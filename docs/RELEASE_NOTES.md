## 소리차트 — 간호기록 음성 녹음 생성기 beta

### 이번 버전 (v0.1.17-beta, 2026-10-17)
- **기록 시각이 대본 내용과 맞습니다**: 무작위 대본·대량 생성의 시그널 날짜·시각을 환자 타임라인과 기록 안의 시계에 맞춰 정합니다 — 간호정보조사는 입원일(외래 입원 낮, 응급실 입원 저녁), 수술 전 설명은 수술 전날 오후·저녁("내일 수술"), 수술 후 기록은 수술 당일 병실 도착 15~45분 뒤, 수술 후 상태기록은 재측정 뒤, 퇴원은 퇴원일 오전, 인계는 교대 시각(07·15·23시), 경과기록은 밤 11시 라운딩 뒤. 날짜는 지난 1년 안으로 잡습니다. 전에는 시그널이 "오늘 ±20일, 아무 시각"이라 "10월 13일 오전 9시 57분 … 수술후설명" 다음에 "2월 12일 수술 당일 … 12시 30분 병실 도착"이 나오곤 했습니다. 퇴원 후 외래 날짜도 퇴원일 뒤로 맞췄습니다(긴 입원 포함).
- **공통 종료 문구 고정**: 시작 문구가 필수 형식(「… 님 [기록종류] 기록입니다」)이면 끝도 녹음 공통 원칙대로 「이상 [기록지 명칭] 마치겠습니다」(간호정보조사지·수술전 간호기록·수술후 간호기록·퇴원 간호기록·인계기록지·경과기록)로 끝납니다. v0.1.14~0.1.16에서는 이 문구가 여러 종료 문구 중 하나로 무작위로만 나왔습니다. 시그널 형식을 "무작위"로 두면 지금처럼 다양한 종료 문구를 씁니다.
- 결과물·검수의 문장 클릭 대본이 원래 문단(시각별 경과기록, 대화형의 한 사람 말 단위)대로 줄을 바꿔 보입니다. v0.1.16-beta에서는 모든 문장이 한 덩어리로 붙어 보였습니다.
- 대량 생성 중 메모리: 녹음 한 건이 끝날 때마다 GPU 캐시를 돌려주고 목소리 참조 캐시를 6개로 제한해, 16 GB Mac에서 몇 건 뒤 스왑으로 느려지던 현상을 줄였습니다.

### 이전 버전 (v0.1.14-beta, 2026-10-17)

- **배액·소변 양상 말투**: "장액혈성/혈성" 같은 한자어 대신 병동에서 쓰는 영어 그대로 — serosanguineous하게(시로생기너스하게), bloody하게(블러디하게), turbid하게(터비드하게), clear하게(클리어하게).
- **종료 문구**: 모든 서식의 기본 종료 문구를 "이상 [기록지 명칭] 마치겠습니다"로 맞췄습니다(간호정보조사지·수술전 간호기록·수술후 간호기록·퇴원 간호기록·인계기록지·경과기록).

### 이전 버전 (v0.1.11-beta, 2026-10-17)

- **수술 후 기록(POD 0)을 병동 범주 순서로 재편**: 환자 확인·도착 → 바이탈 사인·의식 → 가지고 온 주입·배액관 관찰 → 수술 부위 관찰 → 통증 사정 → 약물 투여(항생제·항구토제·항응고제) → 수술 후 처치(산소, DVT 예방 IPC, ice bag, 거상, 압박) → 금식 유지 기간 교육 → 자세·활동 교육 → 배액관 관리 → 도뇨관 관리 → 수술별 관찰·교육 → 알려야 할 증상. 배액관·도뇨관은 관찰과 관리 교육을 나누고, 상처 교육은 알려야 할 증상에 합쳤습니다.

### 설치 (macOS)
1. Apple Silicon은 `-arm64.dmg`, Intel Mac은 `-x64.dmg`를 받아 앱을 Applications로 끌어다 놓습니다.
2. 서명되지 않은 베타 빌드라 첫 실행 시 차단됩니다. **Finder에서 앱을 우클릭 → 열기**를 하거나 터미널에서
   `xattr -dr com.apple.quarantine /Applications/NursingTTS.app` 을 실행한 뒤 여세요.
3. Python 3.10 이상이 필요합니다 (`brew install python`). 인터넷이 없는 PC는 아래 "오프라인 번들"을 쓰세요. 앱을 처음 켜면 **처음 설정 마법사**가 환경 점검 → 백엔드 설치(진행률·예상 시간 표시) → 음성 엔진 → 첫 목소리 등록을 안내합니다. 기본 설치는 보통 2~4분 걸립니다.
4. 목소리 복제 엔진(Qwen3-TTS, 약 6.5 GB)은 마법사나 설정 탭에서 체크해 설치합니다. 엔진 없이도 시스템 음성으로 전체 흐름을 바로 확인할 수 있습니다.

### 설치 (Windows)
`-win-x64.exe` 설치 파일 실행 → 처음 설정 마법사를 따라가면 됩니다. Python 3.10 이상(python.org, "Add to PATH" 체크) 필요. NVIDIA GPU가 있으면 복제 엔진 설치 때 CUDA용 PyTorch를 자동으로 받습니다.

### 인트라넷(인터넷 없는 PC)
이 릴리스의 `nursing-tts-offline-<os>-<arch>-qwen.zip`을 받아 두었다가(또는 인터넷 되는 PC에서 `scripts/build-offline-bundle.sh --qwen --models`로 모델까지 넣어 만든 zip), 처음 설정 마법사 2단계나 설정 → 백엔드의 "📦 오프라인 번들(zip) 가져오기"로 선택하면 Python 설치 없이 백엔드가 뜹니다. 모델이 번들에 없으면 설정 → 로컬 모델의 폴더에 복사합니다.

### 알려진 제한
- 코드 서명/공증 없음 (베타). 자동 다운로드·설치는 서명 뒤에 붙습니다.
- 목소리 복제 품질은 선택한 모델과 GPU에 따라 다릅니다. Mac 16 GB에서는 대량 생성 대신 소량 생성을 권합니다.
